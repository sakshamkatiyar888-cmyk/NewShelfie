# Shelfie 📚

Personal Book Discovery & Reading Tracker

## Features
- Open Library search
- Subject/language/sort filters
- Personal library
- Reading status
- Reading streak
- Notes CRUD
- Optimistic UI
- Authentication flow
- Protected routes
- Dark/light theme
- API caching
- Request retry
